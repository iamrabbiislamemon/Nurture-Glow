# Nurture-Glow Frontend Application

The frontend is a single-page application (SPA) built using React, Vite, and TypeScript.

## Folder Structure

- `/src/components`: Reusable UI elements (cards, headers, layouts)
- `/src/pages`: Top-level application view controllers
- `/src/types`: Consolidated TypeScript interfaces and barrel exports

## Key Scripts

- `npm run dev`: Run local development server
- `npm run typecheck`: Run TypeScript compilation check
- `npm run test`: Run Vitest tests
